# Red Escolar de Pluviómetros de Medellín · v9.0.3

## Videotutorial

Se añadió un modal de bienvenida con el videotutorial oficial:

- Video: https://www.youtube.com/watch?v=ngp1H3UpGx8
- Apertura automática al cargar el sistema.
- Botón permanente **Videotutorial** en la navegación superior.
- Controles de cierre: X, botón Cerrar, tecla Escape y fondo del modal.
- El iframe se descarga al cerrar para detener audio/video.
- Diseño adaptable a escritorio, tablet, móvil y uso embebido en Google Sites.

## Compatibilidad

No se modificó el backend v9.0-secure, la URL `/exec`, la estructura de Google Sheets ni los PIN migrados.
